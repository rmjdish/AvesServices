Guided walkthrough

The same discover-in-OWL, finish-in-Condor workflow from How It Works, but step by step — click a step to see exactly what to do, then mark it done as you go.

Your progress is only saved in this browser

Marking a step as done is a convenience for you alone — it's stored in this browser only (using localStorage), not on any server. It won't follow you to a different device or browser, and clearing your browser's site data will reset it. Nobody else can see your progress, including LHA.

1
Discover — search & browse in OWL
▾

Start on OWL, not Condor — it's public, needs no registration, and has more ways to find what you're looking for. Pick whichever of these fits how much you already know:

  • Know roughly what you want? Use Search Data Dictionary — OWL's recommended keyword search across every variable.
  • Not sure where to start? Browse by Category to explore thematically instead.
  • Want to see what others use? View Popular Variables shows what gets added to baskets most often.
  • Need the same measure across sweeps? Longitudinal Search finds variables tracked consistently over time.
  • Starting from a specific sweep? Search by Year filters by when data was collected.
  • Working across cohorts? The UK LLC Catalogue covers NSHD's linked-data deposits.
  • Or just use the search bar at the top of any OWL page — it scans the whole site.

If you're after early-life or childhood measures: OWL's own coverage data shows early-life coverage (birth to age 25) is smaller in scale than later-life sweeps — the study used simpler instruments in its first two decades, and OWL's cleaning has so far covered later, larger sweeps more completely. If a childhood-era variable doesn't turn up on OWL, that doesn't mean it doesn't exist: Condor always holds the complete variable set, cleaned or not, so check there directly rather than assuming it's unavailable.

Go to OWL → Mark as done
2
Basket — collect variables, download the dictionary
▾

As you find variables you want, add each one to your basket — it persists as you keep browsing, so you can search several different ways (Step 1) and build up one combined list.

When you're ready, download your basket from OWL. It builds a complete Excel data dictionary for you automatically — every variable in your basket is already marked in the Request column, so there's nothing left to fill in by hand.

Prefer not to use a basket at all? You can complete the same dictionary entirely manually instead — download a blank copy and mark variables yourself. Both approaches produce the same file, and can be mixed: do part on OWL, finish the rest by hand.

OWL's basket guide → Mark as done
3
Condor — upload, validate, and finalise
▾

Bring your completed dictionary — from OWL, done by hand, or a mix of both — into Condor using Upload OWL Basket from the OWL menu. It's checked automatically before anything is added, using the same validation OWL itself uses:

  • Missing variable names are skipped and listed by row
  • Anything other than a blank or exact Y in the Request column is skipped and listed
  • Duplicate variable names: only the first is kept
  • A warning if your file would put a single basket over Condor's 500-variable limit
  • Restricted variables are named individually — they aren't imported automatically and need requesting separately

Once it's through validation, your basket is finalised and saved in Condor, ready for the last step.

Mark as done
4
Skylark — submit your formal request
▾

Neither OWL nor Condor can submit your request directly — that last step happens on Skylark. With your basket finalised in Condor, head to Skylark and complete the formal Data Access Request Form to actually apply for the data.

Go to Skylark → Mark as done
