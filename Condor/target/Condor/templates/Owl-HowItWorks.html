How OWL and Condor work together

OWL is where you discover variables. Condor is where you finalise and submit a request. Here's exactly how the two connect.

Two ways to complete the dictionary

The Data Dictionary is just an Excel spreadsheet, marked Y against every variable you want. You can complete it entirely by hand — open a blank copy and mark variables yourself — or build a basket on OWL and let it fill the dictionary in for you automatically.

Why OWL is the better route

OWL has search tools this manual route doesn't: keyword search across the whole dictionary, browse-by-category, and — usefully — searchable documentation, so you can find a variable from a write-up or topsheet rather than already knowing its name. It's the faster, more reliable way to build an accurate list.

Uploading to Condor: Upload OWL Basket

Whichever way you completed the dictionary — downloaded from OWL, or filled in by hand — upload the same file using Upload OWL Basket from the OWL menu. The file is checked before anything is added, using the same validation OWL itself uses:

  • Missing variable name — rows marked Y with no variable name are skipped and listed by row number.
  • Invalid Request variable value — anything other than blank or exactly Y (a lowercase y, N, or a stray note) is skipped and listed with the value found.
  • Duplicate variable names — only the first occurrence marked Y is kept; the rest are listed.
  • Over 500 variables — a warning if the file would take a single basket over Condor's 500-variable limit (see below).
  • Restricted variables found — a highlighted notice naming each one. See below for what this means for your request.
A note on restricted variables

Restricted variables can be added to an OWL basket and downloaded like any other — OWL doesn't block them. But when that file is uploaded to Condor, restricted variables are not imported automatically with the rest of your request. Each one needs to be requested separately; who to contact depends on the specific variable, and that contact is shown when you hover the lock icon next to it on OWL. Check your basket for lock icons before uploading, so you're not waiting on a second round trip after submission.

Maximum basket size: 500 variables

A single basket submission to Condor should contain no more than 500 variables. If your project needs more, either build several smaller baskets from the start, or build one larger list and split it into baskets under 500 before uploading each.
