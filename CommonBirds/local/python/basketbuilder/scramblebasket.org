* SCRAMBLEBASKET(1) -- April 2025

* NAME

   scramblebasket - create a NSHD scrambled dataset from an existing CSV file.

* SYNOPSIS

   scramblebasket  /BASKETID/ /USERNAME/

* DESCRIPTION

   Create a pseudonomised dataset from an existing CSV dataset corresponding to the variables specified in the Condor basket BASKETID created by the user or project USERNAME.

   Resulting datasets are created in 
   #+begin_src 
/xnat/san/SST/baskets.
   #+end_src
