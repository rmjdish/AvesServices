KLG - Includes class conn , a utility class which executes queries. The code contains repetitive references to set up a database connection. I tend to have a class called ConnectionManager which takes care of creating connections as well as pooling them. package-info appears to be auto-generated but serves no purpose.

Some things to do:

  • Everything up until the line "String url=..." should be moved into a constructor so that it is done once. (saves 25 lines of repetitive code)
  • Wherever possible you should use PreparedStatement instead of Statement. Prepared statements help prevent SQL injection errors and they are efficient because the query code is only compiled once.
  • a finally {...} code block should follow each catch(..) {...}. There you should attempt to close statements and result sets so that database resources can be properly flushed or reclaimed.
  • Use connection pooling. See macaw.persistence.production.SQLConnectionManager for an example of how this can be done.
