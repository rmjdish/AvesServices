Baskets help

Your basket is where variables you find get collected. Here's how saving, loading, and sharing work.

Save basket

Saves your current working basket permanently. You'll be given an automatically generated basket name and asked to add a description before it's stored — the description is the main way you'll recognise this basket later, so make it clear.

Save basket →
View current basket

Shows what's in your working basket right now, before it's been saved. This is a temporary, in-progress selection tied to your session — closing the browser without saving loses it.

View basket →
Load / share my basket

Lists every basket you've saved previously, ordered by when it was created, with the description you gave each one. Select one to load it back into your working basket.

My baskets →
Load shared basket

Browse baskets that have been made public by other users and load one into your own working basket — a quick way to reuse a colleague's selection.

Shared baskets →
Tips
  • Your working basket stays in your session only until saved — save it before you navigate away if you want to keep it.
  • Give every saved basket a clear, specific description; the automatically generated basket name alone isn't easy to recognise later in a long list.
Managing your baskets

You can hold multiple saved baskets at once — there's no need to reuse or overwrite an existing one. Use clear, distinct descriptions so each is easy to tell apart later. Once a basket has what you need, use Download Basket from the Baskets menu to export it.

Saving a large basket: automatic splitting

If your basket has more than 500 variables (not counting SERNO, SEX, INF and NTAG1, which are added to every basket automatically), saving it doesn't create one oversized basket — it's split into several saved baskets instead, each with no more than 500 of your own variables.

Before you confirm the save, the save form shows you exactly what will happen: how many baskets will be created and the ID each one will be saved under, e.g. i.shahZZmtbefg_1 and i.shahZZmtbefg_2 for a basket split in two. SERNO, SEX, INF and NTAG1 are included in every one of these baskets, not just the first.

The description you type is used for all of them, with "(Basket 1 of 2)", "(Basket 2 of 2)" and so on appended automatically so you can tell them apart later in your saved baskets list. Once saved, you're shown a simple, read-only summary listing exactly which variables ended up in each saved basket, for reference.

An ordinary basket under the 500 limit is entirely unaffected by any of this — it's saved as one basket, with just the description you typed, exactly as before.

Important: how split baskets are reviewed

If your request has been split into multiple saved baskets, they are reviewed collectively, as one overall request — not as separate, independent submissions.

Requests for a large number of variables may take longer to process, since they go through a more thorough risk assessment before data can be released.

You may be asked to justify your request if your total comes to more than 500 variables across a single submission, even when that submission has been split into several saved baskets to get around the per-basket limit.

Linked variables: what they are, and removing them

Some variables are part of a longitudinal measure — the same underlying thing measured at several different ages or sweeps. When you add one variable from a measure like this, every other variable sharing that same measure is added to your basket automatically alongside it. These are called linked variables, to distinguish them from the one you searched for and added directly.

Right after adding variables, the Basket Management page shows you a breakdown: how many were added because you searched for and selected them directly, how many were pulled in automatically as linked variables, and how many couldn't be added at all because access to them is restricted. Each variable's name, label, and the reason it does or doesn't appear in your basket are all listed in the results table below, and a dropdown lets you filter the table down to just one of these three groups if it's long.

If you only wanted the variable you searched for and not the extra linked ones, a Keep linked variables toggle appears on the same page whenever an add produced any. Switching it off removes just the linked variables from your basket, keeping the ones you added directly. This is fully reversible — switching it back on restores exactly the same linked variables, so an accidental click isn't permanent. The toggle only ever affects the variables from your most recent add action; it doesn't reach back into variables already sitting in your basket from earlier in your session.

Restricted variables are never added to your basket in the first place, so there's nothing for the toggle to remove for those — they're listed for your information, with the reason for the restriction, but the toggle only ever affects the linked group.

Common questions
I saved a basket but can't find it again. +
Check under Load / Share My Basket, not View Current Basket — the current-basket view only ever shows your unsaved, in-progress selection. Saved baskets are listed by creation date rather than by name, so if you have many saved baskets you may need to look through the list using the description you gave each one.
What's the difference between "my basket" and "shared basket"? +
Load / Share My Basket only ever shows baskets you personally saved. Load Shared Basket shows baskets that other users have made public, regardless of who saved them.
Can I un-share a basket later? +
There is currently no option on the save-basket form to mark or unmark a basket as shared yourself — sharing is tracked separately from the normal save flow. If you need a basket shared or unshared, contact LHA using the details in the footer.
